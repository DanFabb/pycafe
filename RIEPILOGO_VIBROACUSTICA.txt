Riferimento: examples/02_cavity_plate_coupled.ipynb (cavita' + piastra CCCC)
Generato: 2026-08-08

Formulazione risolta (Euleriana (w, p), convenzione e^{+j w t}, normale n
uscente dal fluido):

    | Ks + j w Cs - w^2 Ms        -Kc        | { w }   { Fs }
    |                                        | {   } = {    }
    | -rho0 w^2 Kc^T      Ka + j w Ca - w^2 Ma| { p }   { Fa }

    Kc = int_S Ns^T n Na dS       (unica matrice di interazione, compare 2 volte)

Matrice NON simmetrica: e' il prezzo di accoppiare spostamento e pressione.

FASE 0 — CONTRATTO DELLA MESH (physical groups)

Modulo: pycafe/create_geom/conventions.py
Tutto cio' che pyCAFE sa oltre alle coordinate arriva dai physical group.

  ruolo       nomi accettati                    cosa e'
  ---------   -------------------------------   -------------------------------
  fluid       fluid / acoustic / domain         dominio acustico (CHEXA8 3D,
                                                CQUAD4/8 2D)
  structure   plate / structure / shell         dominio strutturale (CQUAD4F);
                                                su mesh accoppiata i suoi
                                                elementi SONO le facce di
                                                interfaccia
  pml         pml / absorbing_layer             strato assorbente; se il gruppo
                                                non c'e', niente PML
  clamp       plate_clamp / clamp / fixed       nodi di vincolo (il tipo di
                                                vincolo lo decide 'support',
                                                non il nome)

  Nomi liberi (qualsiasi altro) = boundary selezionabili da AcousticBC
  (es. "rigid_walls", "inlet", "outlet", "lined_wall", "opening").
  Parete rigida = condizione naturale, non serve alcun gruppo.

Funzioni:
  role_of(group_name)                 -> ruolo di un gruppo, o None
  names_for(role)                     -> alias accettati, canonico per primo
  find_group(groups, role)            -> nome del gruppo che copre quel ruolo
  describe_conventions()              -> stampa il contratto completo

   system = pycafe.prepare_vibroacoustic_system(
       nodes=nodes, groups=groups,
       rho0=RHO0, c0=C0,
       t=T, rho_s=RHO_S, E=E, nu=NU,
       nsm=0.0,
       clamp_group=None,          # default: plate_clamp / clamp / fixed
       support="clamped",         # "clamped" (CCCC, 6 DOF), "simply_supported"
                                  # (solo 3 traslazioni), "free"
       clamp_dofs=None,           # lista esplicita DOF locali 0..5, sovrascrive
                                  # 'support'
       build_coupling=True,       # False -> due domini separati
       interface_sign=None)       # forza l'orientamento della normale (+1/-1)

   Cosa fa internamente (pycafe/core/prepare_vibroacoustic_system.py):
     identify_domains(groups)                       -> fluid / structure
     build_KM_acoustic_domain(nodes, domains, c0)   -> Ka, Ma (1 DOF p / nodo)
     build_KM_structural_domain(nodes, domains, t, rho_s, E, nu, nsm)
                                                    -> Ks, Ms (6 DOF / nodo)
     interface_normals(nodes, iface_conn0, fluid_conn0, sign)
     build_coupling_matrix(nodes, iface_conn0, fluid_conn0, *, sign,
                           num_nodes, dofs_per_node=6)      -> Kc  (6N x N)
     acoustic_coupling_matrix(Kc, rho0)                     -> Mc = -rho0 Kc^T
     interface_area_vector(Kc, dofs_per_node=6)             -> int_S n dS
        (controllo: per una piastra piana su z=Lz deve dare [0, 0, Lx*Ly])

   Contenuto di 'system':
     system["domains"]     -> per ruolo: group, elem_type, conn0 (0-based), nodes
     system["acoustic"]    -> K, M (N x N CSR), elem_type, nodes0
     system["structural"]  -> K, M (6N x 6N), K_red, M_red, idx_free,
                              nodes0, clamped_nodes0, elem_type
     system["interface"]   -> conn0 (facce piastra), nodes0, normals
     system["coupling"]    -> {"Kc", "Mc", "area_vector"} oppure None
     system["props"]       -> proprieta' usate

   Variante solo-acustica: pycafe.prepare_acoustic_system(
       nodes=..., elements=..., boundaries=..., rho=..., c0=..., bc=...,
       groups=None, pml=None)   -> sistema ridotto (Dirichlet applicati).

  Contenitore:
     bc = AcousticBC()
     bc.add_impedance(selection, Z)        Robin: Z scalare, complesso o f(omega)
     bc.add_anechoic(selection)            Z = rho0 c0 (onda piana uscente)

     bc.add_monopole(q, *, position=None, node=None)
     bc.add_distributed_source(q)
     AcousticBC.from_legacy(bc) / bc.to_legacy()   conversione formato vecchio
  Dataclass: VelocityBC, ImpedanceBC, PressureBC, PointPressureBC, MonopoleSource
     MonopoleSource(q, position=None, node=None, distributed=False)
         Q_a = j rho0 omega int Na q dV
  make_admittance(Z, rho, c0)   -> ammettenza specifica A(omega) = 1/Z(omega)
  check_node_index(node, what, n_dof=None)   (indici 0-based)

  Operatori dipendenti dalla frequenza (si costruiscono UNA volta, poi .at(omega)):
     C_op = build_impedance_operator(bc, *, nodes, rho, c0, boundaries, groups,
                                     elements, boundary_dim)
     V_op = build_velocity_operator(bc, *, nodes, rho, boundaries, groups,
                                    elements, boundary_dim)
     Q_op = build_source_operator(bc, *, nodes, rho, elements)
     C_a  = C_op.at(omega)         -> matrice sparsa sulla numerazione PIENA

  Esempio (pareti trattate, zeta normalizzata):
     bc_walls = AcousticBC().add_impedance("rigid_walls", ZETA_WALL)
     C_a = build_impedance_operator(bc_walls, nodes=nodes, rho=RHO0, c0=C0,
                                    boundaries=boundaries, groups=groups,
                                    elements=elements, boundary_dim=2).at(0.0)
     alpha = 4*ZETA_WALL / (1 + ZETA_WALL)^2      # coefficiente di assorbimento

  Smorzamento strutturale: eta_s (isteretico), Ks -> Ks (1 + j eta_s).

FASE 6a — ANALISI MODALE ACCOPPIATA
================================================================================
   f_coupled, modes = solve_vibroacoustic_modal(system, num_modes=12, *,
                          pressure_zero_nodes0=None, eta_s=0.0,
                          blocks=blocks_free, sigma=1.0)
       Autoproblema non simmetrico:
           K = [[Ks, -Kc],      M = [[Ms, 0],
                [0 ,  Ka]]           [rho0 Kc^T, Ma]]
       Autovalori reali positivi per problema conservativo; il residuo
       immaginario del solutore non simmetrico viene scartato.
       modes: colonne impilate [w ; p], n_s righe strutturali poi n_a acustiche.

   Riferimenti non accoppiati (servono a leggere l'accoppiamento):
     piastra in vacuo:  eigsh(K_s, k=8, M=M_s, sigma=0.0, which="LM")
     cavita' rigida:    solve_modal_acoustic_reduced(K_a, M_a, num_modes=5)

   Classificazione di un modo (energia strutturale / totale):
       Es = omega^2 * w^T Ms w ;  Ea = p^T Ma p / rho0
       frac = Es / (Es + Ea)     -> >0.75 plate-like, <0.25 cavity-like
       Il modo a ~0 Hz e' la pressione uniforme della cavita' sigillata
       ("molla d'aria").

Metodo 1 — base di modi accoppiati (biortonormalizzata):

       -> Phi_R, Phi_L, omegas, freqs, biorthogonality, ...

   basis = build_cms_basis(system=None, *, num_structural=15,
               num_acoustic=40, blocks=..., pressure_zero_nodes0=None,
               C_a=None, include_rigid=True)
       -> omegas_s (piastra a secco), omegas_a (cavita' rigida),
          modal_coupling A [m^2], num_structural, num_acoustic
       Forma teorica verificabile:
          Kt = [[diag(ws^2), -A], [0, diag(wa^2)]]
          Mt = [[I, 0], [rho0 A^T, I]]

Proiezione e sweep ridotto (comuni ai due metodi):
   Kt, Ct, Mt = project_coupled_system(basis, *, eta_s=0.0, rayleigh=None,
                                       modal_zeta=None)
   res = solve_coupled_modal_frequency_sweep(basis, frequencies, *, F_s=None,
             F_a=None, eta_s=0.0, rayleigh=None, modal_zeta=None,
             verbose=False, return_modal=False)
       return_modal=True aggiunge "participations" (|phi_c(omega)|).

Controlli tipici: residuo di biortogonalita', |Mt - I|,
|Re(Kt) - diag(omega_c^2)| / max(omega_c^2); con pareti trattate Ct e' densa
(l'assorbimento accoppia i modi).

Errore relativo contro lo sweep diretto:
   err_w = ||res["w"] - result["w"]|| / ||result["w"]||

import numpy as np, pycafe
from pycafe.boundary_condition import AcousticBC
from pycafe.boundary_condition.acoustic_bc import build_impedance_operator
from pycafe.solver.solver_vibroacoustic import (
    build_coupled_blocks, solve_vibroacoustic_modal,
    solve_vibroacoustic_frequency_sweep, expand_pressure,
    structural_displacement_field)
from pycafe.solver.solver_vibroacoustic_modal import (
    build_coupled_modal_basis, build_cms_basis, project_coupled_system,
    solve_coupled_modal_frequency_sweep)
from pycafe.post_processing.post_processing_3d import plot_pressure_3d
from pycafe.create_geom.library import box_with_plate

# 1. mesh
mesh_path = box_with_plate(
    Lx=.4, Ly=.3, Lz=.5, nx=12, ny=9, nz=12, output_path="plate_cavity.msh")
nodes, elements, boundaries, groups = pycafe.load_mesh_with_groups(
    str(mesh_path), verbose=False)

# 2. materiali
air = pycafe.load_fluid("air"); RHO0, C0 = air["rho"], air["c0"]

# 3. sistema
system = pycafe.prepare_vibroacoustic_system(
    nodes=nodes, groups=groups, rho0=RHO0, c0=C0,
    t=1e-3, rho_s=2700., E=70e9, nu=.33, support="clamped")

# 4. smorzamento acustico + blocchi
C_a = build_impedance_operator(
    AcousticBC().add_impedance("rigid_walls", 200.),
    nodes=nodes, rho=RHO0, c0=C0, boundaries=boundaries, groups=groups,
    elements=elements, boundary_dim=2).at(0.)
blocks = build_coupled_blocks(system, C_a=C_a, eta_s=.02)

# 5. modi accoppiati
f_coupled, modes = solve_vibroacoustic_modal(
    system, num_modes=12, blocks=build_coupled_blocks(system))

# 6. sweep diretto
freqs = np.arange(20., 450.5, .5)
F_s = np.zeros(blocks["n_s"]); F_s[dof] = 1.0    # dof: vedi FASE 6b
result = solve_vibroacoustic_frequency_sweep(
    system, freqs, F_s=F_s, blocks=blocks, verbose=False)

# 7. sweep ridotto (opzionale)
basis = build_coupled_modal_basis(blocks=build_coupled_blocks(system, C_a=C_a),
                                  num_modes=40)
res = solve_coupled_modal_frequency_sweep(basis, freqs, F_s=F_s, eta_s=.02)

# 8. post
p_full = expand_pressure(result["p"], result["idx_a"], nodes.shape[0])
plot_pressure_3d(nodes, elements, p_full[:, k], part="abs")

INSIDIE NOTE
================================================================================
- Normale di interfaccia: sempre USCENTE dal fluido. Se il segno risulta
  sbagliato, forzarlo con interface_sign=+1/-1, non correggere a valle.
- Verifica economica dell'accoppiamento: interface_area_vector(Kc) deve dare
  il vettore area esatto dell'interfaccia.
- La matrice accoppiata e' non simmetrica: serve un solutore generale, e le
  basi modali vanno biortonormalizzate (modi destri E sinistri).
- eta_s appartiene allo sweep, non alla base: costruire la base con
  build_coupled_blocks(system, C_a=C_a) senza eta_s, e passare eta_s a
  project_coupled_system / solve_coupled_modal_frequency_sweep.
- Modo a ~0 Hz in cavita' sigillata = pressione uniforme: non e' un errore,
  e' la molla d'aria; si accoppia solo ai modi di piastra che cambiano volume.
- Indici: groups/boundaries dal loader sono 1-based, conn0/nodes0/idx_a sono
  0-based. NodeIndex tiene il contratto.
- Coordinate Gmsh con round-off: per ricostruire la griglia strutturata della
  piastra usare np.unique(np.round(coord, 6), return_inverse=True).
- Modi non eccitati: una forza al centro non eccita i modi con linea nodale li'.
  Nel confronto picchi/modi vanno elencati come "non eccitati", non come errore.
- Ambiente: conda env 'pycafe1'; ffmpeg solo tramite imageio-ffmpeg
  (ensure_ffmpeg()).
- Tetraedri: fuori dal workflow gmsh standardizzato (mesh esaedriche).
