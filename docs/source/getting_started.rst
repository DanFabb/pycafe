Getting started
===============

This documentation provides an introduction to **pyCAFE**, a Python-based
two-dimensional finite element framework for solving acoustic wave problems
in the frequency domain.

pyCAFE is designed for research and engineering applications in acoustics.
It offers a clear and modular environment for defining the fluid medium,
computational geometry, boundary conditions, and for assembling and solving
the acoustic Helmholtz equation.

The framework is particularly suited for reproducible numerical studies and
for extending classical acoustic finite element formulations toward more
advanced modeling approaches.
